### 一、 訂單接收與需求確認階段

1. **系統提示：** 機器人（Robert）主動發布新訂單通知，明確通報**訂單編號（型號）及客戶客製化需求**（例如：特定顏色、零組件外殼要求等）。
2. **人工確認：** 工作人員確認需求後回覆「OK」，系統隨即進入**備料程序**。

### 二、 物料取用與配送階段（正常流程）

1. **庫存檢核：** 系統（Robert）確認庫存狀態，若物料充足，則發出「準備取料」通知。
2. **自動取料：** 系統即時回報當前正在拿取的具體物料名稱。
3. **物料配送：** 由 Logan 將取出的物料配送至工作人員面前。
4. **人機協作交割：**
    - 工作人員取出物料。
    - 工作人員指令「下一個附件/物件」，系統重複取料動作（此循環視訂單需求可能重複多次，如錄音中提到的 4 次取料循環）。
5. **取料完成：** 系統通報「物料拿取完畢」。

### 三、 組裝與訂單結案

1. **組裝作業：** 工作人員收到所有物料後進行手動組裝。
2. **結案與銜接：** 組裝完成後，工作人員指令「OK，下一單」，系統自動跳轉至下一個訂單的型號與客製化需求確認。

### 四、 缺料異常處理機制（例外流程）

若在備料階段發現特定物料短缺，系統將採取以下彈性作業：

1. **缺料通報：** 系統（Robert）通報「目前缺料」，並同步自動**發起補料申請**。
2. **排程優化：** 在等待補料期間，系統不會停擺，會**優先拿取其他充足的物料**或下一個附件，以優化作業時效。
3. **人工補料：** 外部人員完成加料後，系統通報「物料已補齊」。
4. **恢復取料：** 系統重新回到缺料物件的拿取程序，直至該訂單物料全數交付完畢。
